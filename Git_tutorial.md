# Шпаргалка по командам git

## 1. работа с репозиториями

### создать/склонировать репозиторий

```shell
git clone **<https ссылка репозитория>**
git init
```

### управление репозиторием 

```shell
mkdir Folder
cd Folder
```

```shell
rmdir Folder
```

```shell
cd .. 
rmdir Folder
```

## 2. добавление своих учетных данных credentials (email, name)

```shell
git config --global user.name
git config --global user.name "my\_name"
```

```shell
git config --global user.email
git config --global user.email "sobaka@yandex.ru"
```

есть еще user.password, но я не рекомендую)

## 3. Перемещения внутри и между ветками

### изучаем содержимое репозитория 
```shell
git branch -a
```

### переключение на ветку 
```shell
git checkout <Название ветки>
```

### переключение с созданием ветки
```shell
git checkout <Название ветки>
```

### переход по графу (от коммита к коммиту)
```shell
git checkout <первые 5 символов хэша>
```

### переход по графу (от текущего коммита к любому другому коммиту)
```shell
git checkout HEAD^^^ # откат на 3 коммита назад

git checkout HEAD~3 # тоже самое
```

### откатываемся к ветке
```shell
git switch - 
```

## 4. Делаем коммит / вносим изменения

```shell
git add <файл1> <файл2>
git add . 
```

### смотрим статусы файлов в репозитории 
```shell
git status 
```

### удаляем из изменений файл
```shell
git restore --staged <файл1> <файл2>
```

### восстанавливаем исходный тип файла
```shell
git restore <файл1> <файл2>
```

### сам коммит
флаг **-m** от message
```shell
git commit -m "Добавляем текст"
```

## 5. изменение коммитов

```shell
git reset HEAD^
```

```shell
git revert
```

## 6. объединение веток 

### 
```shell
git checkout <выбираете ветку в которую хотите слить изменения>
git merge <имя_ветки-источника новых данных>
```

```shell
git checkout <выбираете ветку в которую хотите слить изменения>
git rebase <имя_ветки-источника новых данных>
```

```shell
git checkout <выбираете ветку в которую хотите слить изменения>
git log
git cherry-pick <хэш коммита> <хэш коммита>
```

## 7. взаимодействие с облачными репозиториями 

```shell
git push <внести изменения>
git pull <забрать изменения>
```

## 8. доп функции для работы с облачными репозиториями 

### локальное удаление ветки
```shell
git branch -d <название ветки>
```
### облачное удаление ветки
```shell
git push origin --delete <название ветки>
```
