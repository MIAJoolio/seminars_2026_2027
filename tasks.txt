Задача 1: Пирожки в столовой
Пирожок в столовой стоит a рублей и b копеек. Определи, сколько копеек останется после покупки n пирожков.
Формат входных данных
a — рубли
b — копейки
n — количество пирожков

Задача 2: Как поделить яблоки 
n школьников делят k яблок поровну. Неделящийся остаток остаётся в корзине. Определи, сколько яблок останется в корзине.
Формат входных данных
Два положительных целых числа, каждое не превышает 10000:
n — количество школьников
k — количество яблок

Задача 3: Расстояние в километрах
Напиши программу, которая определяет полное количество километров по заданному числу метров.
Формат входных данных
Одно натуральное число – количество метров.
